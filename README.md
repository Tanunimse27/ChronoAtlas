# ChronoAtlas 

The world, through time.

ChronoAtlas is an interactive historical atlas that helps users explore events happening around the globe at a selected point in history.

By combining an interactive world map with a timeline, the application will highlight events from the selected year alongside events from the surrounding period.

## Planned Features

- Interactive world map with historical event markers
- Timeline-based exploration from ancient civilizations to the modern era
- Highlighting of exact-year events and surrounding historical context
- Filters for regions and event categories
- Historical event details with source references

## Technology Stack

- Python
- Streamlit
- Folium
- Pandas
- SQLite
- Git and GitHub

## Project Status

Currently under development.

## Vision

To help people understand world history as a connected story, revealing what was happening in different parts of the world at the same time.
